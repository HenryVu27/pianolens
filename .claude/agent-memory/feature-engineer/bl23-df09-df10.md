# BL-23, DF-09, DF-10 (2026-09-29)

## DF-10 (correctness pitch check)
- Every different-pitch aligner match comes from parangonar's ornament step (ornamented note ->
  first performed note within ±2 in [onset-0.25 s, offset]). Legacy rule keeps them all, so the
  check is a no-op on real data (0 dissolved in F-02, stress, calibration sets); BL-20 Part B
  reproduces exactly. 201 such matches on the 100 clean D-08 copies.
- Ornament names in ASAP scores: trill-mark 564, tremolo 355, inverted-mordent 263, wavy-line
  240, trill+wavy 229, turn 129, mordent 55; 4,009 grace notes. partitura calls tremolo an ornament.

## DF-09 (staff numbering)
- partitura `merge_parts` default reassign="voice" keeps staff numbers: one-staff-per-part scores
  all land on staff 1. Fix lives in `align/_adapters.to_part` (per-part consecutive numbering,
  then `normalise_piano_staves`). Mozart PianoCoRe scores use 2/3 or 3/4 plus stray staves.
- Catalogue: zero-event pieces 25 -> 0; Gondoliera LeungM08M 351 cross-staff onsets.
- `iter_all` with a class tuple can yield one object twice: dedupe before remapping.

## BL-23 (experiments/2026-09-29-BL-23-aligner-ornaments/)
- Tight whitelist (pair first + directional pitch sets) flags 6.5% of legacy-tolerated ornament
  notes on clean expert copies (28% of different-pitch ornament matches): players realise
  mordents / inverted mordents on the "wrong" side. Failed N3; not default.
- Post-pass (`align/postpass.py`, 30 ms margin, 100 ms window, LOO expected onset) is default
  (`reassign=True`): absorption 0.114 -> 0.086 in clean dense-N bars; no measurable harm. It
  slightly hurts with the GT alignment (moves 2.2% of dense-N injections onto a written note).
- Script reuses eval_correctness_density + calibrate_expert_check_f08c; one alignment, 4 variants;
  1,004 jobs in 725 s on 12 workers. Calibration limits unchanged under R (only median share of
  bars with error 0.421 -> 0.420).
- Trap: the spec section hash runs to EOF when the prereg is the last section; do not append
  results below it.
