# BL-21 repeated notes + BL-22 phantom extras (2026-09-29)

Pre-registrations: `docs/specs/phone-audio-baseline.md` (sections BL-21 / BL-22, hashes in the
experiment READMEs). Scripts `scripts/bl21_repeated_notes.py {subset,run}`,
`scripts/bl22_phantom_extras.py {labels,analyse,spectro,posthoc}`.

## BL-21
- Outputs `data/interim/pianovam_bl21/` (per-note parquet, summary.json, strata.csv, Aria subset
  MIDI in `aria_amt/`, subset list `aria_subset.csv`).
- Aria-AMT on PianoVAM: 8 recordings (1.45 h audio, one per pianist, 2 pianists dropped by the
  2 h cap). Runs through `transcribe_aria_amt_mac.py`; zsh does not word-split $files, so use a
  bash script with an array (scratchpad run_aria.sh pattern).
- Audit: Confirmed with caveats. The loss is below ~100 ms (16ths > ~150 bpm), not 120. 79% of
  <80 ms Disklavier "repeats" are release echoes (start within 5 ms of the previous release,
  ~0.45x velocity). BL-25 cut-off 100 ms. Take counts: `bl21_repeated_notes.py takes`.
- TRAP: short same-pitch repeats are much softer than other notes (PianoVAM <80 ms median vel 25
  vs 65), and soft notes are missed anyway. Always report a velocity-adjusted drop next to the
  raw one. Some <80 ms Disklavier "repeats" may be key bounces; unverified.
- Rendered MAESTRO controlled set has 0 repeats <80 ms and 14 at 80-120: useless for this.
- pandas: `df.take` is a method; use `df["take"]` for a column named take.

## BL-22
- Outputs `data/interim/henry_takes/bl22/` (PERSONAL). labels.parquet = A-01 alignment labels per
  transcribed note for both models.
- Transcriber pedal (CC64) reads 87-97% down on every take, so pedal-down vs up tests cannot run
  on these nocturnes/waltzes.
- A 2 s "recently sounded" harmonic window has no power (null hit rate ~0.6 in the treble);
  use a concurrent (50 ms) window. Positive controls: PianoVAM false extras 0.37 vs null 0.19.
- The takes are band-limited: 3-6 kHz is 6-13 dB below PianoVAM, 13-19 dB below the rendered
  audio (roll-off near 3.3 kHz in the Op. posth. passage). The A-01 phone simulation does not
  model this. Unaffected takes are just as dark.
- High extras: real narrowband energy at the reported pitch (~10 dB prominence), abrupt, not
  harmonics, not octave-displaced missed notes.
- AUDIT CORRECTED MY READING: the extras are a MELODY (97% white keys G6-G7, stepwise, ~3 notes/s,
  the same 4-note phrases in all 3 affected takes) = a second sound source, not a phone or room
  artefact. My "room/phone artefact" and "no 2nd partial argues against resonance" were wrong.
  Lesson: check sequence structure (steps, n-grams vs permutation) before acoustic explanations.
  Final status Confirmed with caveats; listening list in the README. Old A-01 wording marked
  Superseded in rules/audio.md and the spec.
- Ratio-to-null thresholds cap at 1/q; report the implied share f=(h-q)/(1-q) instead.
